Using Const

  1. Declare three variables (using var, let, const) to store your city, age, and country.
  2. Try reassigning all of them.

Using let

  1. Create a variable using let to store your age.
  2. Print it in the console.
  3. Try changing the value (reassign).
  4. Print again.
  5. Try redeclaring it and see what happens.
